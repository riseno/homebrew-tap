# riseno/homebrew-tap

Homebrew formulae for [k8s-mcp](https://github.com/riseno/k8s-mcp), a safe, read-only-by-default
MCP server for troubleshooting any Kubernetes cluster.

```bash
brew install riseno/tap/k8s-mcp
```

Formulae in `Formula/` are generated and pushed by the k8s-mcp release workflow
(cargo-dist) on each tagged release. Do not edit them by hand.
